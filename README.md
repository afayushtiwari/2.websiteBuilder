# 🌟 Overview

AI Website Builder is a full-stack MERN application that allows users to generate modern websites using AI prompts and deploy them instantly.

The platform combines:
- 🤖 AI-generated website creation
- ⚡ Instant deployment workflow
- 🔐 Secure authentication
- 💳 Stripe payment integration
- 📂 Project management dashboard

Designed with scalability, responsiveness, and clean UI/UX principles.

# ⚙️ Installation

## 📥 Clone Repository

```bash
git clone https://github.com/afayushtiwari/2.websiteBuilder.git
```

---

# 📦 Install Dependencies

## Frontend

```bash
cd client
npm install
```

## Backend

```bash
cd server
npm install
```

---

# 🔑 Environment Variables

Create `.env` file inside `server/`

```env
PORT=8000
MONGODB_URL=your_mongodb_url
JWT_SECRET_KEY=your_secret_key
GEMINI_API_KEY=your_gemini_key
STRIPE_SECRET_KEY=your_stripe_key
CLIENT_URL=http://localhost:5173
```

---

# ▶️ Run Locally

## Backend

```bash
npm run dev
```

## Frontend

```bash
npm run dev
```
